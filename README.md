**How to use this randomizer:**
1. Choose type of randomizer do you want,
2. There is 2 type of randomizer; **max member of group** and **max amount group**,
3. Click one of those button,
4. You will redirect to one of those pages.

**Randomizing by max member of group:**
1. Type name in the text area,
2. Give enter for every name,
3. Then input the amount of maximum members group,
4. And click "Buat Kelompok",
5. Done.

**Randomizing by max amount of group:**
1. Type name in the text area,
2. Give enter for every name,
3. Then input the amount of maximum amount group,
4. And click "Buat Kelompok",
5. Done.
